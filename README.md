# RedGordo 🐈🎀

Aplicación web estática para practicar inglés mediante ejercicios cortos de significado, comprensión auditiva y frases incompletas.

## Funciones

- Preguntas de opción múltiple en orden aleatorio.
- Audio generado por el navegador para practicar escucha.
- Puntaje, rachas y progreso almacenados localmente.
- Repaso específico de respuestas incorrectas.
- Creación manual e importación rápida de tarjetas desde texto.
- Tema claro y oscuro.
- Diseño adaptable para computadora y teléfono.

## Importar tarjetas

Cada línea debe utilizar este formato:

```text
palabra o frase | significado | pronunciación | ejemplo
```

Los datos se guardan en el almacenamiento local del navegador y no se envían a ningún servidor.
